# Manager tools

For store managers, when you need the numbers, a manager-only fix, or a store setting.

Most manager work happens on the same screens the counter uses. A manager sees extra buttons there, such as an override or a refund. The pages in this section are the ones only a manager opens.

| I need to... | Go to |
|---|---|
| See what sold, what it cost and what we made | [Sales Report](sales-report.md) |
| Find the right report for a question | [Reports](reports.md) |
| Void a card charge or give card money back | [Card voids and refunds](card-refunds.md) |
| Lay out zones, racks and safes on the store map | [Set up the store map](store-map.md) |
| Change a store setting or connect an outside system | [Settings](settings.md) |
| Sort mail that is not a customer inquiry | [Other mail](other-mail.md) |
| Stop marketing email for someone, or see who gets it | [Marketing contacts](marketing-contacts.md) |
| Close the month with the bookkeeper | [Month-end close](../admin/month-end.md) |

Which buttons need a manager is listed on [Roles and sign-in](../start/roles.md).
