## `firearm_stock_summary`

`POST /api/method/ffl_core.api.agent.firearm_stock_summary`

**Auth (derived from code):** Roles resolved at runtime via `STOCK_READ_ROLES`.

How many firearms the store has on hand, and how many of them can be sold.

A gun is on hand while its Serial No is Active. It is not for sale when the POS
picker would not offer it: held on a ticket or order, reserved by a web or
GunBroker order, consigned out, or a customer's transfer gun.

**Returns:** {on_hand, for_sale, not_for_sale, antiques, by_warehouse: {warehouse: count}, by_type: {firearm_type: count}}. Antiques are counted in on_hand and are not in the A&D book.
