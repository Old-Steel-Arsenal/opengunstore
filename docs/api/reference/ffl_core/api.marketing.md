## `record_consent`

`POST /api/method/ffl_core.api.marketing.record_consent`

**Auth (derived from code):** Roles: Marketing User / Sales Manager / System Manager

Record that a contact agreed to marketing email: Not Subscribed becomes Subscribed.

For a consent given outside the website (at the counter, on the phone, on a paper form). A contact
that unsubscribed, bounced or complained is refused: this never puts one back (a manager can, on
the contact's form, with a reason). Who recorded it, the channel and the note go on the log.
Refused while marketing is switched off.

| arg | type | required | default | description |
|---|---|---|---|---|
| `contact` | string | yes | — | The Marketing Contact (its email address). |
| `channel` | string | yes | — | Where the consent was given, in a word or two ("in store", "phone"). |
| `note` | string \| null | no | `None` | Anything worth keeping with it. Optional. |

**Returns:** {"contact": the address, "status": the status now, "changed": False when it was already Subscribed}.
