## `resubscribe`

`POST /api/method/ffl_core.api.marketing.resubscribe`

**Auth (derived from code):** Roles: Sales Manager / System Manager

Put a suppressed contact back to Subscribed.

For a contact that unsubscribed, bounced or complained. The reason is required and goes on the log
with who did it.

| arg | type | required | default | description |
|---|---|---|---|---|
| `contact` | string | yes | — | The Marketing Contact (its email address). |
| `reason` | string | yes | — | Why this contact may be emailed again. |

**Returns:** {"contact": the address, "status": "Subscribed"}. Refused for a contact that is not suppressed.

## `unsubscribe`

`POST /api/method/ffl_core.api.marketing.unsubscribe`

**Auth (derived from code):** Roles: Sales Manager / System Manager

Stop marketing email to a contact.

Its status becomes Unsubscribed, with who did it and the reason on the log. A contact already
Unsubscribed, Bounced or Complained is left as it is.

| arg | type | required | default | description |
|---|---|---|---|---|
| `contact` | string | yes | — | The Marketing Contact (its email address). |
| `reason` | string \| null | no | `None` | Why, in a few words. Optional. |

**Returns:** {"contact": the address, "status": the status now, "changed": False when it was already suppressed}.
