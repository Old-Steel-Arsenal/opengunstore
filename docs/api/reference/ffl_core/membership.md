## `cancel_membership`

`POST /api/method/ffl_core.membership.cancel_membership`

**Auth (derived from code):** Roles: Sales Manager / System Manager

Cancel a membership. By default it runs to the end of the period it is paid for and is not

renewed. ``end_now`` ends it today: the current invoice's deferred lines get today as their
service stop date, so what is still deferred becomes income today. The invoice itself is never
cancelled; a refund is a credit note.

| arg | type | required | default | description |
|---|---|---|---|---|
| `membership` | string | yes | — | Membership name (Active, Past Due or Suspended). |
| `reason` | string | yes | — | Why (kept on the membership). |
| `end_now` | — | no | `0` | 1 to end it today instead of at the period end. |

**Returns:** The membership's panel row.
