## `lookup_serial`

`POST /api/method/ffl_core.api.firearm_intake.lookup_serial`

**Auth (derived from code):** Roles: Sales User / Sales Manager / Stock Manager / System Manager

Look up a firearm by serial to short-circuit duplicate intakes.

Resolves via the canonical Serial No table first, then falls back to
FFL Acquisition.serial in case the Item has been deleted.

| arg | type | required | default | description |
|---|---|---|---|---|
| `serial` | string | yes | — | Serial number (whitespace-stripped; blank returns not-found). |

**Returns:** {found: false} — nothing on file; {found: true, source: "erpnext", item, acquisition} — already an Item (acquisition may be null); {found: true, source: "acquisition_only", acquisition} — an FFL Acquisition exists but its Item is gone.
