## `pair_terminal`

`POST /api/method/ffl_core.signing_terminal.pair_terminal`

**Auth (derived from code):** Guest — no session; the endpoint verifies the caller itself (HMAC signature, HTTP Basic credentials or a one-time token).

The tablet trades a pairing code for its device key (Guest).

The code works once. Any tablet paired to the same terminal before stops
working. 10 tries per 10 minutes per IP address; after 50 wrong codes from
anywhere in 10 minutes, pairing pauses until the window passes.

| arg | type | required | default | description |
|---|---|---|---|---|
| `code` | string | yes | — | The 6 digits shown on the Signing Terminal record. |

**Returns:** {"secret": the device key (shown this once), "terminal_name"}.

## `terminal_poll`

`POST /api/method/ffl_core.signing_terminal.terminal_poll`

**Auth (derived from code):** Guest — no session; the endpoint verifies the caller itself (HMAC signature, HTTP Basic credentials or a one-time token).

What the tablet should show now (Guest, every 2 seconds).

Limited per tablet (2400 an hour) and per IP address (30000 an hour: a shop's
tablets together, about 16 of them polling all hour).

| arg | type | required | default | description |
|---|---|---|---|---|
| `secret` | string | yes | — | The tablet's device key. |

**Returns:** {"paired": false} for an unknown or switched-off tablet (the page goes back to pairing); {"paired": true, "token"} when the counter sent a link (handed out once); otherwise {"paired": true, "idle": true, "terminal_name", "store_name", "form_4473_url"} — form_4473_url is the store's FastBound customer 4473 page, or "" when the store has no electronic 4473.
