## `connect_my_mailbox`

`POST /api/method/ffl_core.api.crm.connect_my_mailbox`

**Auth (derived from code):** Roles: Sales User / Sales Manager / System Manager

Start connecting your own mailbox to the POS: the address of the provider's sign-in page.

For a staff member whose mailbox an administrator set up as an OAuth Email Account with them as
its connected user; they sign in to their own mail account, not the administrator. Frappe's own
Authorize button needs read access to the Connected App, which staff do not have.

| arg | type | required | default | description |
|---|---|---|---|---|
| `email_account` | string \| null | no | `None` | The Email Account to connect. Optional when you have only one. |
| `success_uri` | string \| null | no | `None` | Where to land after signing in (a path on this site). Default: CRM. |

**Returns:** str: The sign-in address to open. Refused for an Email Account whose connected user is someone else, or that does not sign in with OAuth.
