## `click`

`GET /api/method/ffl_core.marketing.track.click`

**Auth (derived from code):** Guest — no session; the endpoint verifies the caller itself (HMAC signature, HTTP Basic credentials or a one-time token).

A tracked link in a marketing mail (Guest): a redirect to *u*.

Only when *s* is this site's signature of *u* and *u* is an http(s) address; anything else gets a
400 and no redirect. Records the contact's first click on that link in campaign *c* while Track
clicks is on and the campaign was sent to them. 5000 calls an hour per IP address.

| arg | type | required | default | description |
|---|---|---|---|---|
| `u` | string \| null | no | `None` | Where the link goes. |
| `c` | string \| null | no | `None` | The campaign. |
| `t` | string \| null | no | `None` | The contact's token from the mail. |
| `s` | string \| null | no | `None` | The signature of *u*. |

**Returns:** A 302 redirect to *u*, or a 400 plain-text "This link is not valid."
