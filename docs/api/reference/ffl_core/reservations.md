## `reserved_counter_serials`

`POST /api/method/ffl_core.reservations.reserved_counter_serials`

**Auth (derived from code):** Role-filtered: callers without Roles Sales User / Sales Manager / Stock Manager / System Manager receive an EMPTY result instead of an error.

Counter-hold registry for one Item's in-stock serials — the DISPLAY half.

Drives the Pending pill on the Item form's Serial Numbers tab. Same data as
:func:`counter_holds`, behind the shipping-role gate, because it names which
regulated serials sit on which order.

| arg | type | required | default | description |
|---|---|---|---|---|
| `item_code` | string | yes | — | Item whose in-stock serials to check. |

**Returns:** {serial: {source, ref, kind, tooltip, url}} — only held serials appear.

**Permissions:** Canonical shipping roles. A caller WITHOUT the role gets an empty {} back silently — no error is raised — so an empty result from THIS function is not proof of "no holds". Anything enforcing a rule must call :func:`counter_holds` instead; see its docstring for what went wrong when that distinction did not exist.
