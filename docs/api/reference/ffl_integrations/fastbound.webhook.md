## `fastbound_event`

`POST /api/method/ffl_integrations.fastbound.webhook.fastbound_event`

**Auth (derived from code):** Guest — no session; the endpoint verifies the caller itself (HMAC signature, HTTP Basic credentials or a one-time token).

Single FastBound webhook entry point (guest, HMAC-verified).

**Payload:** FastBound's webhook JSON body; the event name selects the handler. The X-FastBound-Signature header must carry a valid HMAC over the raw body (secret configured in FastBound Settings).

**Returns:** 200 with a minimal body ({ok, event/handled/error}) on success. 401 when the HMAC signature is missing, malformed or fails — and also, word for word, when the integration is switched off on this site (see below). Every other failure path logs + returns 200 to keep FastBound from retrying.
