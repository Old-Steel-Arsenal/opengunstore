## `lookup_and_create`

`POST /api/method/ffl_integrations.atf.ez_check.lookup_and_create`

**Auth (derived from code):** Roles: Sales User / Sales Manager / Stock Manager / System Manager

Live-verify an FFL number via the configured EZ Check provider and

upsert the result into ATF FFL Record. Used by the "+ Lookup by FFL #"
button on the ATF FFL Record list view to seed a new row in one click.

| arg | type | required | default | description |
|---|---|---|---|---|
| `ffl_number` | string | yes | — | FFL number (separators tolerated; loose format check). |

**Returns:** {ok, found, status, name, licensee_name, licensee_dba, license_type, expiry_date, address, street, street2, city, state, zip}.

**Raises:** ValidationError: The number is missing, malformed, or the provider returns NotFound.

## `re_verify_all`

`POST /api/method/ffl_integrations.atf.ez_check.re_verify_all`

**Auth (derived from code):** Roles: System Manager

Re-run live EZ Check for every ATF FFL Record.

Useful after the scraper / cache schema changes (e.g. License Type
derivation, address column persistence) so existing rows are filled in
without manual clicks. Skips gracefully when a row no longer exists
upstream.

**Returns:** {updated, not_found, failed, total, errors: ["<record>: <error>", ...]}. not_found counts rows EZ Check did not list (C&R records are left as entered; a dealer's expiry is voided).
