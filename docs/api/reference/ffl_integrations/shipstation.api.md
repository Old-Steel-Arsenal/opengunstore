## `push_shipment`

`POST /api/method/ffl_integrations.shipstation.api.push_shipment`

**Auth (derived from code):** Roles: Sales User / Sales Manager / Stock Manager / System Manager

Push a submitted order to ShipStation (the Pending Order Ship action).

Staff buy the label in ShipStation. Synchronous; idempotent (a second
call after success is a no-op); persists nothing on API failure, so a
retry after fixing the cause is safe. Independent of the Dispose step.

| arg | type | required | default | description |
|---|---|---|---|---|
| `sales_invoice` | string | yes | — | Submitted Sales Invoice with a resolvable ship-to. |

**Returns:** {ok, shipstation_order_id, shipstation_status, ...} — or {ok: True, already: True, ...} when previously pushed.

**Permissions:** Counter shipping roles.
