GunBroker FixedPriceListingFailed webhook: a listing failed, so record why and re-check the gun.

**Payload:** GunBroker's ``{ItemTitle, ItemID, SKU, Quantity, "Error Message"}`` JSON. The item number, SKU and error text are read; the text is stored as plain text on the gun's (or item's) GunBroker sync error.
