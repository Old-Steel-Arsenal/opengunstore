### Version 1.3.1 — November 19, 2026

#### New

- **Date of birth and ID numbers where you work.** The customer form has a new Identification tab, between Details and Profile, with the date of birth and the ID documents (they used to sit on the Profile tab). The contact panel at the register now lists the customer's date of birth and every stored ID number under Email, Phone and Loyalty. The panel is read-only. This only shows when Store Customer ID Numbers is turned on in FFL Settings.
- **Gender is read from the ID.** Scanning an ID now fills in the customer's Gender (Male or Female) when the ID says so.

#### Improved

- **Scanning an ID now updates a customer you already have.** This is a change from before: scanning the ID of an existing customer used to leave their record alone. Now it brings the record up to date:
  - The Driver License and CCW numbers and expiry dates are replaced with the ones on the new ID.
  - A date of birth or gender that is empty gets filled in. One that is already filled in is never overwritten.
  - If the address on the ID is different, the customer gets the new address as their main one. The old address is kept and noted on the customer's timeline. An address that another customer also uses is left as it is, and a new one is added instead.
  - The name is never changed. If the name or date of birth on the ID does not match the customer, you are asked before anything is saved.

  The register shows Scan ID on a customer you picked, so you can scan a renewed or replaced ID there. This all happens only when Store Customer ID Numbers is turned on in FFL Settings. With it off, nothing changes.

#### Fixed

- **A Texas License to Carry is saved as two IDs.** The card carries two numbers: its own, and the holder's driver license. Before, only the carry number was saved, filed as a Driver License. Now one scan saves a CCW row (with the card's expiry) and a Driver License row. The card has no driver license expiry, so that row has none. If you scanned a Texas License to Carry before, scan it again and the customer gets the correct two rows.
