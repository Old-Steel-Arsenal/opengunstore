### Version 1.8.0 — November 27, 2026

#### New

- **Return in Transit.** When the carrier brings back a gun that was shipped to another dealer, open its disposition and press Return in Transit: the disposition is undone in the bound book, the gun goes back into stock today, and a counter order returns to Pending Orders so it can be shipped again.

#### Improved

- **Sales Report cost matches the books.** The cost of each gun sold is now its value on the day it left the store for that sale, the same amount the accounts record. A sale that has not been handed over yet is marked so, and a gun found on two sales is flagged for review.

#### Fixed

- **Price Hub cost history.** The cost history chart now only shows the distributors the store buys from.
