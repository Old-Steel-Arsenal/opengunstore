### Version 1.3.3 — November 20, 2026

#### New

- **A Check column on 4473 Records.** Compliance → 4473 Records can now show what an extension says about each form, such as the AI 4473 check: Passed, Held, Let through or Not checked, linked to the check's page. The column only appears when an installed extension fills it, so a store without one sees the report as before.
