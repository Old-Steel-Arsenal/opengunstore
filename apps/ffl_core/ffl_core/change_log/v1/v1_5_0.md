### Version 1.5.0 — November 24, 2026

#### New

- **Short description and search-engine text on the Item.** An Item's WooCommerce section now has Short Description, SEO Title, Meta Description and Focus Keyword. When filled in, they go to the store with the product: the short description shows next to the price, and the SEO fields set the page title and the text search engines show. Leave one empty and the store keeps what it already has.
- **Drop-ship listings take the catalog's optimized copy in full.** When a drop-ship product has rewritten copy in the catalog, listing it or refreshing its copy now also fills in the short description and the search-engine text, not only the name and description. Copy that was not rewritten never replaces what the Item already has.
