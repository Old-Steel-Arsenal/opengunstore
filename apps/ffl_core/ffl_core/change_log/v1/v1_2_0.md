### Version 1.2.0 — November 18, 2026

#### New

- **Items that come in options, made in one screen.** When you create an item, tick Comes in options, type each option (for example Fits or Color) and its values, and a table lists every combination. Fill in each one's SKU, price, cost and pre-order slots — or fill a whole column at once — and Save creates them all. The item's page then shows the same table: change a price or slots right there, add a value to make new combinations, or untick one to stop selling it. Group existing items brings items you already have into the set. On the website it is one product with a dropdown for each option.
