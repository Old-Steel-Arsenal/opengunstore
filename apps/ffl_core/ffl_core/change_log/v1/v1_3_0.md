### Version 1.3.0 — November 19, 2026

#### New

- **Customer memory on leads and deals.** With an AI extension that remembers customers switched on, a lead or deal shows a Memory card: what the customer said they want, their budget, state, trade-in, how they like to be contacted and questions still open, with a one-line summary of where things stand. Each line the customer said ends with "said Nov 12"; click it to read that message. Fix or add lines with Edit memory in the "…" menu: what you write stays as you wrote it. Update memory reads the latest mail now, and Clear memory empties the card. Draft reply uses the memory to pick products, nearest the customer's budget first. Without the extension nothing changes.
