### Version 1.3.0 — November 19, 2026

#### New

- **Customer memory on leads and deals.** The side of a Lead or Deal page has a Memory card that sums up what the customer has told you: the guns they want, budget, state, trade-in, how they like to be contacted, and questions still unanswered. Click "said …" next to an entry to see the original message. Use Edit memory to fix or add to it, Update memory to refresh it from the latest mail, and Clear memory to start over. When you draft a reply, the draft now uses the memory. It is off by default: install the OSA AI extension 0.18.0 and turn on "Remember customers with AI" in its settings, and the memory fills itself in. With it off, the card only shows when it already has something in it. Entries you changed by hand are never overwritten by the AI, and nothing from a record you are not allowed to see is shown to you.

#### Improved

- **GunBroker mail is filed under the right person.** GunBroker's sold, won and transfer notices no longer turn the other side's email address into an Other mail lead. When the same GunBroker member asks you more questions, they go onto the one lead that member still has open instead of starting a new one.

#### Fixed

- **Gunsmith deposits and labor are never taxed by accident.** If the register's tax template would charge tax on a gunsmith deposit, or on labor that is meant to be tax-free, the sale is now stopped with a message to switch to the company's default tax template. Before, the customer was quietly charged extra.
- **A web order picked up in the store keeps its own gun.** When you start the 4473 on a pickup ticket, the list now offers the gun that order reserved, not another gun of the same model. Saving the ticket with a different gun is refused.
- **GunBroker tracking numbers are saved for orders already marked shipped.** If an order was already marked shipped on the GunBroker website, the POS used to keep failing and never sent the tracking number. It now sends it.
