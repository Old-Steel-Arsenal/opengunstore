### Version 0.10.0 — November 14, 2026

#### New

- **My tasks.** The sidebar has a *My tasks* page that lists everything assigned to you. A task stays there until you press *Done*, and one you have not finished shows again each day.
- **Hold a gun for a deal.** From a CRM deal, a salesperson can hold a gun on the deal by serial number for 48 hours; the person who placed the hold can extend it once, and a manager can after that. While it is held, the register and Sales Invoices refuse to sell it to anyone but the deal's customer unless a manager approves, and the website shows it as out of stock. It is off until the store turns it on in Lead Mail Settings.
- **Website connector can make changes.** A store can now let Website Connector Managers change the website from an AI assistant, not only read it. Which changes are allowed is set by the store; none are until it sets them.
- **Marketing contacts.** A manager can keep a list of marketing contacts with each person's consent status, website activity and an unsubscribe page. It is off until the store turns it on in Marketing Settings.

#### Improved

- **Refused website requests are logged.** When the POS refuses a request to the website connector, the connector log now keeps it with the reason.
