### Version 0.10.3 — November 15, 2026

#### Security

- **Framework update with security fixes.** The POS now runs Frappe 16.56, ERPNext 16.55 (with its security fixes), Frappe HR 16.53 and Frappe CRM 16.0.3.

#### Changed

- **Max Discount applies to every sale.** An item's *Max Discount* now holds on every line it is sold on: the register, Create Order, web and GunBroker orders. A member price stops at it, and the line says so.
- **Tickets from an earlier day.** A POS ticket dated before the current shift can no longer be changed.

#### New

- **Sell requests and held guns from an assistant.** An assistant connected to the POS can find sell requests, read a gun offered, record the offer and mark it accepted, and hold or release guns for a deal. Receiving the gun is still done at the register once it is in the store.

#### Fixed

- **Products with an empty image file.** A product whose distributor image is an empty file no longer stays off the website: the push leaves that image out and lists the product with the rest. New items no longer pick an empty high-resolution image.
