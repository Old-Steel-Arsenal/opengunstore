### Version 0.6.0 — October 30, 2026

#### Improved

- **Tidier forms.** Customer, Supplier, Item, Serial No, receipts, invoices and the store's own forms now use both columns evenly, keep rarely used sections folded, and show shorter help text.
- **Tidier pages.** Create Order, Receive Goods, Pending Order, Cash Drawer, Stocktake, Storage Locations and the other store pages have cleaner spacing and fit better on a phone.
- **AI assistant can do more.** The store's AI connector can now look up and run every action your role allows, open counter tickets and work-order deposits, and list shipped web orders that still need disposing.

#### Fixed

- **Adjust Quantity.** Setting an item's stock no longer changes the value of the units already on the shelf, and counts register sales that are not closed yet.
- **Create Order checks.** Create Order now refuses the same guns the scanner refuses: held, in custody, out on consignment, reserved for a web order, or possibly sold on GunBroker.
- **Card refunds.** Partial refunds round correctly, and pressing refund twice can no longer refund twice.
- **Cash orders with change.** Editing a cash order where change was given now records only what the customer actually paid.
- **Web orders.** Sales tax collected on the website lands on the sales tax line; in-store pickups are booked once, on the day they are completed; a cancelled web order that is paid again reopens.
- **Selling from stock.** Filling an order from stock now updates the website and GunBroker, and a gun that comes back from a sale is listed again where it was listed before.
- **Receive Goods.** The previous private seller is cleared after each receive.
