### Version 0.2.3 — October 27, 2026

#### New

- **Save a card at the terminal and charge it later.** With the customer's signed authorization, a card paid at the terminal can be kept on file and charged later against a counter order's balance. It is off until a manager turns it on in the Payments settings.
- **Consigned guns can be listed on GunBroker.** A consigned gun now lists like any other gun in stock, as long as its consignor is recorded; the sale pays the consignor's share the same way a counter sale does.

#### Fixed

- **Guns with a very long model code list on GunBroker.** GunBroker used to refuse these listings; they now go up normally.
